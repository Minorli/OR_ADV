contracts 下是设计合同，不会自动创建腾讯云资源。fixtures 是虚构样例，不可导入生产。templates 是留档模板，不是已经完成的审核、备案或法律文件。

references 的 HTML 可以离线打开。文件名中的“线下结算版”为历史命名，当前线上范围以本包为准：不标价、不支付、不管理缴退款。若参考页面的文案、字段或状态与本包详细合同不一致，按本包开发，并修正产品页面。

本包中的平台事实基于 2026-10-15 的核对资料；实施时核对当前官方页面和实际账号。用户确认事实、建议实现和待主理人确认的规则分别表述，不把建议当成最终业务决定。
