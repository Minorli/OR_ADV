## 第二版原型的下级入口

“我的”六格进入安全问答、基础控车、进阶控车、练车与活动、积分兑换、车队手册；下方另有核心职责、积分说明、联系我们、商务合作。主理人还能进入资料待审队列和栏目／咨询管理。

- **资料**：保存草稿 → 选择真实照片 → 确认用途并提交 → 主理人按版本通过或退回。每车轮胎单独准备；不因上传完成自动认证。不收集证件号、血型、病史或证照照片。
- **练习记录**：选择技能 → 保存本人短片 → 提交 → 主理人核对 → 查看逐版记录。改交、撤回与复核保留不可覆盖的版本；题库、示范须由负责人核定。
- **公开栏目**：编辑段落／职责／联系／项目 → 保存未公开草稿或确认授权后发布。主要联系办法与栏目补充信息分别维护，公开页合并去重。
- **商务与兑换**：本人留下联系办法及问题并同意用途 → 提交私有咨询 → 主理人回复或本人撤回。未知结果沿用原提交标识重试；不生成订单，不扣分，不承诺库存或兑现。
- **往期回顾**：主理人整理授权照片和公开HTTPS直连MP4 → 有效参加者投稿并分别同意公开 → 主理人审核。相册数来自可读照片；未配置影片不显示假播放成功。

## 版本、身份与云端边界

本机演示可验证图片、60秒／8MB内短片的持久保存及审核流程。云端短片目前没有已验收的有界上传能力：原件保留本机并提示等待，不伪造已上传或可审核状态。图片使用独立私有接口与不透明资料标识；私人资料不能作为公开相册素材。

前后台在恢复页面、私有读取和提交前后核对当前身份；换人或权限变化时清空旧表单、审核队列及私人URL，同一身份保留未保存编辑。服务端权限与版本检查始终生效，隐藏按钮不是权限保护。

用户已说明业务规则将逐项调整。收费、固定名额、竞速、观察期退出、外部转正、考核门槛及兑换扣分均等待明确说明；代码不从原型图片推导并执行这些新政策。
