# 主理人原型与页面实现

2026-10-16。正式小程序名称：**OriginalRally原始拉力**（用户确认名称已审核通过，未代登录平台核验）。本轮版本 `0.2.0-test.4`。

## 参考与视觉

依据主理人提供的 [元宝原型 v2](https://yuanbao.tencent.com/sc/XWHhLfsyfPxsiS9)，实际打开了首页、排行、历史、我的及页面结构。采用黑色背景、橙色强调、图片封面、紧凑信息行和六宫格入口，不复制网页里的手机外壳、状态栏及元宝提示。

| 用途 | 颜色 |
|---|---|
| 页面／卡片／分隔 | `#0A0A0A`／`#1A1A1A`／`#2A2A2A` |
| 强调色 | `#FF6B00` |
| 主文字／辅助文字 | `#F5F5F5`／`#A8A8A8` |

橙底主按钮使用深色文字；状态同时保留文字。原生导航和Tab图标一起调整，报名、行前资料、积分与员工页沿用同套配色。

## 页面与功能

- **首页**：三张原生轮播、近期招募图片卡、难度短杠、实际日期和余位。默认筛选招募中，个人当前行程继续可直达。
- **排行**：本人成长积分卡、已同意公开的创始成员横卡、推荐和实际积分榜。未同意公开分值者不显示分值；不编造名次、里程或头衔。
- **历史**：独立公开Tab，仅查询已结算活动；按月份和名称／区域筛选，查看公开详情。每批最多读取10页并保留继续加载入口，按已加载记录倒序展示；不发送长介绍、名单或私人资料到列表。
- **我的**：居中本人头像与身份、三项真实统计、六个可用快捷入口。保留昵称／头像编辑、公开同意、员工入口和演示控制；本人申请仍在非Tab“我的同行”中。

原型中的价格、固定内部／外部名额、竞赛、观察期退出、品牌赞助、荣誉、视频和问答不会自动成为业务规则或已实现功能。报名与积分继续执行既有服务端约束。
