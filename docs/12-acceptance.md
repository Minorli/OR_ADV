# 验收清单

以下是实施时应执行的用例，不是本资料包已跑通过的产品测试。记录环境、提交版本、前置数据、步骤、预期、实际结果和证据；无真实云/手机条件者标待执行，不打勾。

重点自动化：状态迁移、积分、并发名额、幂等、角色和跨年；重点真实环境：微信身份、数据库事务、安全规则、隐私授权、体验版、手机与恢复。

## 发布门槛

所有阻断项通过，特别是越权、超额、重复积分、数据环境隔离、备案/适用资质及恢复。非阻断外观问题记录负责人和修复期限。规则尚未主理人确认的项目，不能靠开发者悄悄采用示例值达标。

交接工具自测和交互原型浏览器测试只证明对应文件/工具能运行，不等于上表产品验收通过。
