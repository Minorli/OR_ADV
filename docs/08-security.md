# 身份、权限与隐私

## 三种后台身份不能混用

1. 微信公众平台：管理员、项目开发者/运营者、体验成员。决定谁开发、上传、管理版本或体验。
2. 腾讯云：公司账号及被授权身份，决定谁操作环境、函数、数据库、存储、日志和账单。
3. 产品内员工：owner/operator/leader/checkin，决定谁发布活动、审核、核验和结算。

三者不会自动互相授予。被加成开发者不能自动读取所有云资源；有云权限不能自动作为产品领队；体验者不能获得员工接口权限。

## 服务端身份与角色

微信原生云函数入口使用当前 SDK 提供的可信微信上下文取得 OpenID/AppID；根据应用建立 users 与 membership。不要接受 payload.openid、payload.role 或用户自填 memberId 作为当前身份。

如改为 HTTP 或独立 CloudBase 环境认证，必须另行验证 token/ticket、签发者、受众、有效期和访问范围，不能照搬前端伪造身份。不要为了登录方便给所有云函数开放匿名员工操作。

当前oradv仅接受微信小程序原生调用，不挂HTTP/Web/定时等混合入口；`getWXContext()`依赖运行时上下文，混合调用存在实例残留风险，不能只校验AppID/EnvId就当作已消除。[官方说明](https://docs.cloudbase.net/cloud-function/instance)。

| 操作 | member | checkin | leader | operator | owner |
|---|---|---|---|---|---|
| 本人申请、取消、查积分 | 本人 | 本人 | 本人 | 本人 | 本人 |
| 查必要活动名单 | 否 | 授权场次 | 授权场次 | 本俱乐部 | 本俱乐部 |
| 出发/结束核验 | 否 | 授权阶段/场次 | 授权场次 | 本俱乐部 | 本俱乐部 |
| 审核/确认/发布/结算 | 否 | 否 | 默认仅提交现场结果 | 是 | 是 |
| 手工冲正、授权员工 | 否 | 否 | 否 | 默认否 | 是 |

这是 proposed 权限矩阵；可缩小，不可由前端随意扩张。所有入口校验 clubId、活动范围、角色有效期和资源归属。撤销角色后实际失效，不能仅删除菜单。

## 客户端与数据库

敏感集合禁止客户端直接写。即使客户端安全规则严格，云函数拥有服务端访问能力，仍需每次鉴权和字段白名单。公开读接口从独立投影或白名单返回，不能“把整条记录发给前端但不显示”。

图片上传限制用途、大小、类型和所属人；资格材料不能使用永久公开 URL。活动公开图与私密材料存储路径和权限分开。日志只保留必要技术字段和脱敏对象ID，严禁整份名单/证件/请求体打印。

## 隐私字段清单

| 信息 | 用途与时机 | 限制 |
|---|---|---|
| 微信内部标识 | 建立和恢复本人账户 | 不展示、不用于公开榜单 |
| 昵称 | 个人界面及自愿榜单 | 榜单与推荐分别选择，可退出 |
| 可选头像 | 本人资料页主动选择后保存 | 不默认公开，不进入员工目录、推荐或积分榜 |
| 必要联系电话 | 申请及现场联络，按必要性收集 | 仅有权工作人员，不公开 |
| 资格结果/有效期 | 活动准入与安全核验 | 优先存结论，不默认收原件照片 |
| 签到和完成记录 | 名单清点、积分和纠错 | 不默认持续定位，不公开轨迹 |
| 健康/紧急联系人 | 仅确有必要的高风险活动 | 另评必要性、敏感信息规则和单独同意；不全员强收 |

数据保存时长须结合服务、争议和法律要求确认，未决字段留空；禁止承诺“永远保存”或编造法定年限。注销流程需停止登录与公开榜单，对必要留存部分说明理由、期限和访问限制，按最终规则删除/匿名化。备份到期也要有处理机制。

## 上线隐私步骤

列清实际接口与 SDK → 填公众平台用户隐私保护指引 → 前端按实际能力触发说明与必要同意 → 拒绝处理 → 撤回/注销入口 → 真机验证。不要声明未用定位却调用定位，不要同意前采集手机号。

分清产品用户协议、隐私同意、线下服务约定、风险告知。线上“我已阅读”不能替代真实安全措施，也不能用免责条款消除依法应承担的责任。

## 0.2a的成员身份与受限资料

memberKind与staff_roles、qualifications分别核对。主理人认定身份需revision与依据，前端字段或成员编号不能作为授权依据。编号后8位仅供通过既有可信渠道查找同名成员；不在公开推荐里返回内部成员ID、员工角色或核验材料。

俱乐部推荐与积分榜分别征求同意。未同意积分公开时，推荐响应不含成长分和完成次数；退出或注销后依据权威记录停止公开读取。集合细节放activity_briefings，不出现在公开活动投影；待确认、候补、取消和无关员工读取均拒绝。

新增管理页面仍完全依赖服务端权限，不以隐藏菜单保护。授权撤销／过期、旧无范围现场角色、本人主理人到期锁死等均有失败测试；未把本地模拟证明当成真实数据库规则证明。

## 个人头像

使用微信原生 `chooseAvatar` 与昵称填写能力；拒绝或不提供头像仍可登录和报名。头像仅通过本人的 `profile.avatar.save` 保存，不接受客户端成员ID、文件ID、远程URL或路径。云函数独立校验JPEG/PNG格式、64KiB字节与尺寸；仅该保存接口放宽请求上限并执行单独限频，普通RPC限制保留。

云存储维持客户端禁止直读、直写。每次上传使用唯一新路径，事务再次核对当前账号及revision后关联，失败只清理本次未绑定文件。成功后的旧图清理失败不撤销已经保存的资料，技术日志只含操作和错误码，不记录图片内容、文件标识或临时URL。数据库不保存base64或短期URL。

本人读取头像时按当前有效账号签发显示链接，公开接口不返回头像；注销后停止后续签发。已取得的临时链接存在有效期，不能承诺已发链接即时撤销。删除、失败清理和存储规则均需在实际测试云验证。
