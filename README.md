# OR ADV · 原始拉力

原始拉力摩托车俱乐部的微信小程序，帮助成员参加活动，也让负责人把名单、核验和积分记清楚。

一个俱乐部，成员200人以内，活动约每月一次或更频繁。活动包括非铺装越野、技能训练和多日穿越，不包含比赛；食宿交通自行安排。线下服务真实收费，小程序不标价、不接线上支付、不管理缴退款台账。

## 当前版本

`0.2.0-test.3`（0.2a代码与模拟体验版），10个原生页面。已实现：

- 主理人核定创始成员；符合资格、规则与名额条件时直接确认参加。
- 普通成员申请后看到线下缴费提示，由管理员确认；候补和待资格核验不提示立即缴费。
- 成员目录、身份核对、员工授权和技能资格管理，业务身份与后台权限分别判断。
- 俱乐部推荐默认核心成员优先，积分榜按实际记录排序，公开同意分别设置。
- 本场同行：确认参加者查看行前资料、个人准备清单和本人实际核验记录；取消后停止后续资料读取。
- 员工名单搜索与阶段筛选、成员编号核对、当日出发／返回、未返回待办。
- 单场自动结算、幂等重试、不可覆盖流水、冲正及积分对应的活动名称。

模块演示版预置24名虚构成员、11场活动、78条报名、6份行前资料和39笔积分流水。进入“我的”切换普通车友、创始成员或主理人即可查看；入门场次保留空位供新申请。重置按当天重新生成日期，使用独立v3存储，保留旧版演练数据。具体路径见 [演示指南](docs/18-beta.md#模块演示数据)。

个人资料支持登录后填写昵称、主动选择头像并保存；头像只用于本人界面，拒绝头像仍可参加活动。云版沿用可信微信上下文，本机预览仍为演示身份与本地文件。真实接入的剩余条件见 [微信登录与头像](docs/18-beta.md#微信登录后设置昵称和头像)，无需将AppSecret放到前端。

**仍使用设备本地模拟数据，尚未部署真实测试云。** 不同手机的数据不共享；实际微信身份、云数据库事务／规则和真机结果需独立验收。公开联系和行前资料的示例不可用于真实招募。最新验证及预览状态见 [HANDOFF.md](HANDOFF.md)、[VALIDATION.md](VALIDATION.md) 和 [PROJECT_STATUS.json](PROJECT_STATUS.json)。

200人成员目录已做本地分页与权限验证；每场30人、年度奖励快照30人的当前内测上限仍保留。全员累计报表、历史积分迁入和年度快照分批扩容属于0.2b。

## 快速开始

需要Node.js 22+、npm、Python 3和手机。代码在Linux迭代，官方CI可生成手机预览码；Mac微信开发者工具作为可选模拟与调试方式。

```sh
git clone git@github.com:Minorli/OR_ADV.git
cd OR_ADV
npm ci
npm ci --prefix cloudfunctions/oradv --ignore-scripts
cp config/local.example.json config/local.json
# 填写本项目AppID；已有local.json时保留并编辑，别覆盖。
npm run build
```

默认构建 `mock/test`，不创建资源或购买套餐。模拟版暂不需要EnvId。已有上传密钥和权限时，按 [内测指南](docs/18-beta.md) 在Linux生成预览码；也可以在Mac导入构建后的 `app/miniprogram/`。

```sh
npm run dev           # 监听TypeScript修改，方便本地迭代
npm run typecheck     # 严格类型检查
npm test              # 领域、云入口、构建与原生页面集成测试
npm run test:tools    # 交接工具、产物与上传预检测试
npm run check         # 类型、测试、构建、文档与契约检查
npm run pack:preview  # 打包已构建的模拟版供Mac导入
```

监听结束后先执行一次 `npm run build`，再预览或打包。最终元数据绑定实际部署文件的SHA256；构建失败、文件变化、私密文件或符号链接会阻止预览和打包。

## 业务与权限

创始／核心身份由主理人核定。报名直接确认覆盖首次申请、取消后重报及候补获席；仍核对资格、截止和名额，不挤掉已确认人员。普通成员等待管理员核对线下安排，系统没有付款状态或缴费金额字段。

报名不扣成长积分，确认参加或签到不自动发完成分。活动结束后按冻结规则逐人事务结算。年度积分按真实完成时间的北京时间年份归属。推荐展示不改积分，成员身份不授予员工权限；用户可分别退出推荐与积分榜。

## 工程结构

| 路径 | 内容 |
|---|---|
| `app/miniprogram/` | 原生TypeScript、WXML、WXSS，车友与员工页面 |
| `shared/` | 身份、报名、资料、权限、积分规则及事务接口 |
| `cloudfunctions/oradv/` | 微信可信身份入口和CloudBase适配器 |
| `tests/` | 领域、云边界、原生模板／导航、页面及工具测试 |
| `docs/`、`contracts/` | 产品设计、状态／数据／接口合同、验收和运维 |
| `scripts/`、`config/` | 构建预检、初始化工具及配置模板 |
| `references/` | 原始浏览器原型与历史参考资料 |

根目录 `AGENTS.md` 按最初要求保留；具体工程约定见 [开发规则](docs/development-rules.md)。原始HTML是设计参考，当前实现及真实验证以交接记录为准。

## 配置与贡献

`config/local.json`、上传私钥、云凭据、真实名单与数据导出不进Git。私钥放仓库外，本地配置只存路径。测试和正式EnvId必须不同；最新离线结构计划为 `config/database-plan.v2.json`，计划不代表远端已应用。

首次owner由可信部署者初始化，普通注册用户不会自动成为管理员。正式联系、活动规则、身份依据与积分由实际负责人核定。提交用 `feat:`、`fix:`、`docs:` 等前缀，PR列出行为变化与实际验证；积分、名额、权限和隐私变更补对应回归测试。
